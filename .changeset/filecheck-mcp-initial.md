Initial release: MCP server for the Filecheck API. Stdio CLI (`npx filecheck-mcp`) plus an embeddable `createFilecheckMcp` factory with capability-shaped tools — check_file, fix_file, validate_pdf, optimize_file, render_previews, get_job, list_jobs, delete_job, list_catalog, get_report, save_artifact.
